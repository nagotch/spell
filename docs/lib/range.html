    ライブラリ — クラス

    Range

    範囲。a..b / a..=b が作る

    a..b は終端を含まない範囲、a..=b は終端を含む範囲で、値はこの型になります。変数に保持できます。a > b のときは降順になります（並びの集合は昇順の場合と同じで、順序だけが逆です。たとえば 5..0 は 4, 3, 2, 1, 0）。

    フィールドとメソッド

    シグネチャ内容
    lo開始値（フィールド）
    hi終端値（フィールド）
    incl終端を含むなら 1、含まないなら 0（フィールド）
    rev向きを反転した範囲（プロパティとして r.rev と書く）

    注意

    • Range に __str__ は無いので、そのまま出力はできません
    • 反復子 RangeIter には書き戻し（__set_current__）が無いため、for のループ変数への代入はコンパイルエラーになります

    RangeIter — 範囲の反復子

    Range.__iter__() と int.__iter__() が返す反復子です。直接作るものではありません。昇順・降順の両方を扱い、終端を含む範囲では端の値を返し終えたことを内部の印で覚えます。
