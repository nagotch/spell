    ライブラリ — クラス

    str

    文字列。文字コードの列を包む組み込みクラス

    文字列リテラル（"..." と '...' の両方が使えます）を作ると、自動でこのクラスの値になります。中身は文字コードの配列で、フィールド chars: [int] で直接触れます。文字列は不変です。添え字への代入はできず、書き換えはメソッドが返す新しい文字列で表します。

    エスケープは \n \t \\ \" \' \0 があり、それ以外の文字をエスケープするとその文字自体になります（\r は改行ではなく文字 r です）。

    フィールド

    名前型内容
    chars[int]文字コードの列。そのまま読み書きできる（書き換えると文字列自体が変わる）

    メソッドと演算

    シグネチャ内容
    len文字数（バイト数ではなく文字コードの個数）。プロパティとして s.len と書く
    s[i]i 番目の文字だけからなる長さ1の str。添え字は配列と同じく回り込む（s[-1] は最後の文字、s[s.len] は先頭の文字）。空文字列への添え字は不定。文字コード（int）が欲しいときは s.chars[i]。添え字への代入はできない
    s?[i]安全添え字。範囲内かどうかを返し、比較の中では範囲外が比較全体を偽にする（詳しくは array の安全添え字の節）
    s[i:j]スライス。i 以上 j 未満の部分文字列（新しい str）。端は省略でき、負の添え字は末尾から数え、範囲外は端に丸める
    s + t連結した新しい文字列（__add__）
    s == t / s != t中身の比較（__eq__ / __ne__）
    s < t / s <= t辞書順（文字コードの列としての大小）。共通部分が等しければ短い方が小さい（__lt__ / __le__）
    starts_with(t: str) -> boolt で始まるかどうか
    ends_with(t: str) -> boolt で終わるかどうか
    find(t: str) -> intt が最初に現れる位置。無ければ -1。空の t は 0
    contains(t: str) -> boolt を含むかどうか
    split(sep: str) -> [str]sep で分割した配列。区切りが連続・端にある場合は空文字列が含まれる。sep が空文字列の場合は分割せず、自分だけからなる配列を返す
    join(a: [str]) -> str自分の文字列を区切りにして [str] の要素をつないだ文字列。sep.join(a) の形で使う
    to_int() -> intatoi 式の変換。先頭の空白（スペース・タブ・改行など）と符号を読み、数字が続く間だけ読む。数字以外で止まり、数字が無ければ 0
    replace(old: str, new: str) -> strold の重ならない出現を左から全部 new に置き換えた新しい文字列。old が空文字列の場合は、各文字の間と両端に new を挟む（Python と同じ）
    count(sub: str) -> intsub の重ならない出現回数。空の sub は長さ + 1（Python と同じ）
    strip() -> str前後の空白（スペース・タブ・改行・CR など）を取り除いた新しい文字列
    upper() -> strASCII の小文字（a-z）だけを大文字に変えた新しい文字列。それ以外の文字はそのまま
    lower() -> strASCII の大文字（A-Z）だけを小文字に変えた新しい文字列。それ以外の文字はそのまま
    rev逆順にした新しい文字列（プロパティとして s.rev と書く）

    条件と反復

    条件（if / while の条件など）に文字列を書くと、__bool__ により「空でなければ真」で判定されます。for c in s は1文字ずつの str を返し、ループ変数への代入は元の文字列へ書き戻されます（代入された文字列の先頭の文字で置き換わり、空文字列なら何もしません）。

    StrIter — 文字列の反復子

    s.__iter__() が返す反復子です。直接作るものではありません。__next__() は1文字の str を返し、__set_current__(v) が、現在位置の文字を v の先頭の文字で置き換えます（これが for のループ変数への代入の書き戻しの実体です）。

    注意

    • 文字列に __hash__ があるため Dict のキーにできます
    • __str__ は自分自身を返します
    • 長さは文字コードの個数です。マルチバイト文字もコード列として数えるため、見た目の文字数とは一致しないことがあります
