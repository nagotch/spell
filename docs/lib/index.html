    ライブラリ

    ライブラリ

    起動時に読み込まれる prelude が用意する型と関数、およびコンパイラ組み込みの一覧です。項目ごとに個別ページがあり、使い方と実行確認済みの例を載せています。名前やメソッド名、日本語のキーワードで検索できます。

      基本の型

      str 文字列。文字コードの列を包む組み込みクラス int 64ビット符号つき整数 bool 真偽値。true / false と短縮形の T / F array<T> 配列。リテラル [1, 2, 3] が作る、要素型 T の列

      コレクション

      Dict<K, V> 辞書。キーが無ければ既定値を生やす defaultdict 式 Vec<T> 伸びる配列。末尾への追加が均し定数時間 Deque<T> 両端キュー。Queue としても Stack としても使える SegTree<T> セグメント木。点更新と区間への二項演算がどちらも O(log n) LazySegTree<T, F> 遅延セグメント木。区間への作用の適用と区間の積がどちらも O(log n)

      座標と範囲

      Pos2 二次元座標。リテラル (1, 2) が作る Pos3 三次元座標。リテラル (1, 2, 3) が作る Range 範囲。a..b / a..=b が作る

      組み込み

      print 値を文字列化して改行つきで標準出力へ出す eprint print と同じ文字列化で、標準エラー出力へ出す exit その場でプログラムを終了する min 引数のうち最も小さい値を返す（可変引数） max 引数のうち最も大きい値を返す（可変引数） abs int の絶対値を返す

      入力

      read_int 標準入力から整数を1つ読む。in の実体 read_ints 整数を n 個読んで [int] にする。in[n] の実体 read_ints2 整数を h 行 × w 列で読んで [[int]] にする。in[h][w] の実体 read_ints_dec 整数を n 個読み、各要素から 1 引く read_token 空白区切りのトークンを1つ読む。in_str の実体 read_tokens トークンを n 個読んで [str] にする。in_str[n] の実体 read_line 1行をそのまま読む。in_line の実体 read_str 標準入力の残りを全部読む

      出力

      print_int 整数を標準出力へ出す（改行は付かない） print_str 文字列をそのまま標準出力へ出す（改行は付かない） print_yn 真なら Yes、偽なら No を1行出す。yn の実体

      引数とファイル

      FileData read_file の結果。ok と text を持つ args コマンドライン引数全体を [str] で返す read_file ファイル全体を読んで FileData で返す write_file ファイル全体を書き出す。成功したら真

      文字

      chr 文字コードから長さ1の文字列を作る

      初期値ファクトリ

      zero_int 0 を返す初期値ファクトリ zero_bool 偽を返す初期値ファクトリ zero_str 空文字列を返す初期値ファクトリ zero_pos2 原点 (0, 0) を返す初期値ファクトリ zero_pos3 原点 (0, 0, 0) を返す初期値ファクトリ zero_array 空配列を返す補助関数

      個別ページのないもの

      __println / __eprintln（print / eprint の実体）、__count_range（@n の実体）、__dict_is_prime / __dict_next_cap（Dict の内部用）は、利用側から直接使うものではないため個別ページはありません。一覧はリファレンス §16にあります。
