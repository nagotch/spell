    ライブラリ — クラス

    int

    64ビット符号つき整数

    整数は64ビット符号つきで、コンパイラが直接扱う生の値です（箱詰めされません）。大きなリテラルもそのまま書けます。オーバーフローは2の補数で巻き戻り、エラーにはなりません。ゼロ除算は未定義です（多くの場合クラッシュします）。

    演算

    シグネチャ内容
    a + b / a - b / a * b加減乗（__add__ / __sub__ / __mul__）
    a / b床除算（Python 式）。-7 / 2 は -4（__div__）
    a % b床除算に合わせた剰余。-7 % 2 は 1（__mod__）
    a == b ほか比較（__eq__ / __ne__ / __lt__ / __le__）。bool との比較もできます
    __hash__()恒等（値そのもの）。Dict のキーに使える
    __str__()10進表記。負数もそのまま変換できる

    反復

    for i in n のように整数を反復対象にすると、__iter__ が RangeIter(0, n, 1, 0) を返し、0 から n - 1 までを返します。n が 0 以下なら1回も回りません。糖衣の i@n や @n も同じ実体です。
