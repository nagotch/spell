    ライブラリ — クラス

    LazySegTree<T, F>

    遅延セグメント木。区間への作用の適用と区間の積がどちらも O(log n)

    遅延評価つきのセグメント木です。SegTree の演算 op / 単位元 e に加えて、区間への作用（型 F）を扱い、区間への作用の適用と区間の積をどちらも O(log n) で行います。

    作用まわりの3点セット（作用の単位元 idf、作用を要素へ適用する mapping、作用同士の合成 composition）は Act<T, F> にまとめて渡します。spell の引数は self を含めて6個までという制限があり、必要な6点をそのままでは渡せないため、この形になっています。Act は注釈つきの変数に入れてから渡すのが確実です（act: Act<int, int> = Act(0, add_map, add) のように）。

    composition(f, g) は「g を適用した後に f を適用する」合成を返します（AtCoder Library と同じ規約）。op / mapping / composition には、名前付き関数か fn 型の注釈つき変数へ入れたラムダを渡してください。

    Act — 作用の3点セット

    シグネチャ内容
    Act(idf: F, mapping: fn(F, T) -> T, composition: fn(F, F) -> F)作用の単位元、要素への適用、作用同士の合成をまとめる
    idf作用の単位元。mapping(idf, x) == x が必要
    mappingmapping(f, x) は要素 x へ作用 f を適用した値
    compositioncomposition(f, g) は「g の後に f」の合成

    メソッドと演算

    シグネチャ内容
    LazySegTree(n: int, e: T, op: fn(T, T) -> T, act: Act<T, F>)長さ n、全要素 e で構築する
    LazySegTree(a: [T], e: T, op: fn(T, T) -> T, act: Act<T, F>)配列 a の内容で構築する
    set(i: int, x: T)位置 i の要素を x に置き換える（積まれた作用は押し下げてから置く）
    get(i: int) -> T位置 i の要素を返す
    prod(l: int, r: int) -> T半開区間 [l, r) の積。空区間は e
    all_prod() -> T全区間の積
    apply(i: int, f: F)位置 i の1点へ作用 f を適用する
    apply(l: int, r: int, f: F)半開区間 [l, r) へ作用 f を適用する
    len要素数（プロパティとして t.len と書く）

    注意

    • 添字・区間の範囲外アクセスは未定義です（検査はしません）
    • mapping(f, x) は、作用後のノード値が作用前のノード値 x だけから決まるものでなければなりません。例えば区間代入で区間和を取りたい場合は、要素を (合計, 長さ) の組で持ち、mapping が長さを使える形にします（下の「区間代入＋区間和」の例）
    • mapping(idf, x) == x、composition(idf, f) == f、composition(f, idf) == f、composition の結合則、そして作用と演算の整合性 mapping(f, op(x, y)) == op(mapping(f, x), mapping(f, y)) の成立が前提で、遅延の押し下げはこの前提のもとで無条件に行われます

    代入の例では、作用 F を「代入する値そのもの」とし、単位元を -1 で表しています（代入する値は 0 以上だけ、という約束のもと）。mapping は要素の長さ x.y を使って区間の合計を計算し直します。
