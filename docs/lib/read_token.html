    ライブラリ — 関数

    read_token

    空白区切りのトークンを1つ読む。in_str の実体

    式 in_str の実体です。先行する空白（スペース・タブ・改行・CR）を読み飛ばし、空白に当たるまでの並びを1つのトークンとして読みます。

    関係する糖衣構文

    • >>> 対象, 対象, ...（糖衣集 §02）

    関連項目

    • read_tokens — トークンを n 個読んで [str] にする。in_str[n] の実体
    • read_line — 1行をそのまま読む。in_line の実体
    • read_int — 標準入力から整数を1つ読む。in の実体
    • str — 文字列。文字コードの列を包む組み込みクラス
