    ライブラリ — クラス

    array<T>

    配列。リテラル [1, 2, 3] が作る、要素型 T の列

    配列リテラル [1, 2, 3]、詰め物つきの生成 [fill; n]、空の [] が作ります。リテラルは評価のたびに新しい配列が作られます（前に作った配列が上書きされることはありません）。[fill; n] の fill が配列リテラルのときは、スロットごとに中身までコピーされるため、行同士が共有されることはありません。fill が変数や呼び出し結果のときは、同じ値が全スロットに入ります。

    配列は容量を持ちます。作りたての配列は容量＝要素数です。

    メソッドと演算

    シグネチャ内容
    len要素数（プロパティとして a.len と書く）
    a[i]要素の読み書き。添え字は回り込みます（下の「添え字の回り込み」参照）
    a?[i][j]...安全添え字。全段の範囲を検査する読み取り専用の形（下の「安全添え字」参照）
    a[i:j]スライス。i 以上 j 未満の部分配列（要素をコピーした新しい配列）。端は省略でき、負の添え字は末尾から数え、範囲外は端に丸める
    append(v) -> int末尾に要素を足し、新しい要素数を返す。コンパイラが処理する組み込み操作（下の「append と別名」参照）
    a + b連結した新しい配列（__add__）
    a * nn 回繰り返した新しい配列（__mul__）
    a == b / a != b中身の比較。順序比較（< / <=）は無く、エラーになる
    sort()昇順に並べ替える（インプレース）。安定ソートではない（等しい要素の前後関係は保たれない）。要素型に __lt__ が必要
    sorted() -> [T]並べ替えた新しい配列（元の配列は変わらない）。要素型に __lt__ が必要
    sum() -> T全要素を先頭から + で畳み込んだ値。要素型に __add__ が必要。空の配列では結果は不定
    min() -> T / max() -> T最小・最大の要素。要素型に __lt__ が必要。空の配列では結果は不定
    count(v: T) -> intv と等しい要素の個数。等しさは要素型の == で判定する
    rev逆順にした新しい配列（元の配列は変わらない。プロパティとして a.rev と書く）
    sort_range(lo: int, hi: int)sort / sorted の内部補助。通常は直接使わない

    添え字の回り込み

    通常の添え字 a[i] は、実効添え字を i % a.len（% と同じ Python 式で、負数でも 0 以上）として解釈します。そのため a[-1] は最後の要素、a[a.len] は先頭の要素を指し、読み書きのどちらでも同じです。入れ子の配列では段ごとに回り込み、座標添え字 a[p] も成分ごとに回り込みます。長さ 0 の配列は余りが取れないため、添え字アクセスは不定です。範囲外を厳密に判定したい場合は安全添え字を使ってください。str の添え字も同じく回り込みます。

    安全添え字

    a?[i][j]... は範囲チェックつきの読み取りです。対象の直後に ? を1回だけ置き、後ろに通常の添え字の連鎖を続けます。単独で書くと「連鎖の全段とも範囲内か」を表す bool になり、比較の直接の被演算子として書くと、どこかの段で範囲外なら比較全体が false（!= でも false）になります。対象と各添え字はちょうど1回だけ評価され、範囲チェックは浅い段から順に短絡します。対象にできるのは配列と str だけで、代入先には使えず、連鎖比較の中でも使えません（どちらもコンパイルエラー）。

    append と別名

    append は prelude のメソッドではなく、コンパイラが処理する組み込み操作です（メソッドでは呼び出し元の変数を付け替えられないため）。対象にできるのは、変数・フィールド・配列の要素など、スロットを持つ場所だけです（(a + b).append(x) のような一時値への append はエラー）。容量に空きがある間は同じブロックが伸びて別名からも見えますが、容量を超える append では新しいブロックへコピーして対象の変数だけが付け替わります（別名や、引数として渡した先の呼び出し元には伝わりません）。

    条件に配列を書くと「空でなければ真」で判定されます（__bool__）。配列には __hash__ がありますが、書き換え可能なため、辞書のキーにした後で中身を変えるとそのエントリは引けなくなります。

    ArrayIter — 配列の反復子

    a.__iter__() が返す反復子で、Vec と Deque の反復にも使われます。配列そのものへの反復では、ループ変数への代入は要素へ書き戻されます（__set_current__）。反復中に append した場合、容量内の append は反復にも伸びが見え、容量を超えて付け替えられた後は、反復子は元のブロックの範囲をたどります。
