    ライブラリ — 組み込み

    print

    値を文字列化して改行つきで標準出力へ出す

    prelude の関数ではなく、コンパイラが直接書き換える組み込みです。引数は1つだけです。値を文字列化して、改行つきで標準出力へ出します。複数値を空白区切りで出したいときは文形の put を使います。

    文字列化の規則: 文字列はそのまま、数値は10進、bool は true / false、配列は要素を空白区切り（入れ子も平らに）、クラスは __str__ の結果です。__str__ の無い型（Range、Dict など）はエラーになります。

    関係する糖衣構文

    • << 式（糖衣集 §01）
    • put 値, 値, ...（糖衣集 §01）

    関連項目

    • eprint — print と同じ文字列化で、標準エラー出力へ出す
    • print_int — 整数を標準出力へ出す（改行は付かない）
    • print_str — 文字列をそのまま標準出力へ出す（改行は付かない）
    • print_yn — 真なら Yes、偽なら No を1行出す。yn の実体
