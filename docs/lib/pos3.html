    ライブラリ — クラス

    Pos3

    三次元座標。リテラル (1, 2, 3) が作る

    Pos2 の三次元版です。式の位置で (1, 2, 3) と書くとこの型のリテラルになります。要素ごとの演算と比較を備え、__hash__ があるため Dict のキーにできます。

    フィールド

    名前型内容
    xint第0成分
    yint第1成分
    zint第2成分

    メソッドと演算

    シグネチャ内容
    p + q / p - q要素ごとの加減（__add__ / __sub__）
    p * nint とのスカラー倍（__mul__）
    p == q / p != q要素ごとの等価性
    p < q / p <= q辞書順（x、次に y、次に z の順で比較）
    p[i]成分の読み取り。p[0] が x、p[2] が z。範囲外は検査されない
    __hash__()成分からのハッシュ。Dict のキーに使える
    __str__()空白区切り（"1 2 3" の形）

    注意

    • 入れ子配列への添え字 a[p] は a[p[0]][p[1]][p[2]] と同じです（第0成分が外側）
    • __bool__ は無いため、座標を条件に書くのはコンパイルエラーです
    • ゼロ値は zero_pos3() です

    • 座標添え字 a[p]（糖衣集 §04）
