    ライブラリ — 関数

    zero_array

    空配列を返す補助関数

    呼ぶたびに新しい空配列を返す補助関数です。主な用途は、型を引数に渡す構築（Deque([int]) など）で要素型が配列のときに、ゼロ値ファクトリとして自動で使われることです。戻り値の要素型は「不明」で、どの配列型とも緩く一致します。直接使う場合は、代入先の注釈で要素型を決めてください。

    関連項目

    • array<T> — 配列。リテラル [1, 2, 3] が作る、要素型 T の列
    • Deque<T> — 両端キュー。Queue としても Stack としても使える
    • Vec<T> — 伸びる配列。末尾への追加が均し定数時間
    • zero_int — 0 を返す初期値ファクトリ
