    ライブラリ — クラス

    Dict<K, V>

    辞書。キーが無ければ既定値を生やす defaultdict 式

    構築には既定値ファクトリが必須で、d: Dict<str, int> = Dict(zero_int) のように書きます。ファクトリは「無かったキー」を生やすための既定値を作る関数で、キーごとに呼ばれます。型引数を構築に明示すれば、注釈なしでも d = Dict<str, int>(zero_int) と書けます。

    読み取り d[k] は、キーが無ければファクトリで作った既定値を登録してから返します（grow-on-read、Python の defaultdict 式）。そのため、存在確認だけのつもりの読み取りでも辞書は育ちます。存在だけを見たいときは has を使ってください。ファクトリの値が読み取りで観測できるため、Vec / Deque のような引数なし構築や、型を引数に渡す構築はありません。

    メソッドと演算

    シグネチャ内容
    d[k]読み取り。キーが無ければ既定値を生やして返す（__getitem__）
    d[k] = v書き込み。上書きしてもキーの挿入位置は変わらない（__setitem__）
    has(key: K) -> boolキーの有無。読み取りで生えたキーも「有り」になる
    keys() -> [K]挿入順のキー配列のコピー
    lenエントリ数（プロパティとして d.len と書く）

    キーに使える型

    キーに使えるのは __hash__ と __eq__ を持つ型で、等しいキーは等しいハッシュを返す必要があります。int / bool / str / 配列 / Pos2 / Pos3 などが使えます。Dict 自身には __hash__ が無いため、辞書をキーにはできません。また __str__ も無いため、辞書そのものを出力することはできません。

    反復

    for k in d はキーを挿入順に列挙します。反復は開始時点のキー並びのスナップショットに対するもので、反復中に増えたキーは列挙されません。反復子（DictIter）には書き戻しが無いため、ループ変数への代入はコンパイルエラーになります。条件に辞書を書くと「空でなければ真」で判定されます。

    内部では mixed_hash / find_slot / insert_entry / grow_table というメソッドも持っていますが、実装の都合で公開されているだけで、利用側から呼ぶものではありません。
