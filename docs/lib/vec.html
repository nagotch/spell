    ライブラリ — クラス

    Vec<T>

    伸びる配列。末尾への追加が均し定数時間

    末尾への追加が容量の倍増で均し定数時間になる、可変長の配列です。通常の配列（array）の append と違い、Vec の append は本物のメソッドで、付け替えはオブジェクト内部で完結します。そのため別名や呼び出し元にも成長がそのまま見えます。

    構築は、引数なしの v = Vec()（要素型は int）、型引数つきの v = Vec<str>()、注釈つきの v: Vec<str> = Vec()、既定値ファクトリを渡す v: Vec<int> = Vec(zero_int)、型を引数として渡す v = Vec(str) の各形で書けます。引数なしの場合、バッファの埋め草は要素型の既定値（int は 0、bool は偽、str は空文字列、Pos2 / Pos3 は原点、[T] は新しい空配列）で補われます。要素型がクラス・関数型の場合は自動で補えないため、ファクトリを渡してください。

    メソッドと演算

    シグネチャ内容
    append(v: T)末尾へ追加する。戻り値はない
    len論理要素数（プロパティとして v.len と書く）
    v[i]内部バッファへの直接の読み書き（__getitem__ / __setitem__）。下の注意参照
    to_array() -> [T]論理要素数分の通常配列のコピー

    添え字の注意

    v[i] は内部バッファへそのまま届くため、論理要素数以上の添字も検査されません。容量の範囲では埋め草（ファクトリの値）が見え、容量を超えた添え字は不定です。通常の配列のような添え字の回り込みもありません。安全に読みたい範囲は len で確認してください。

    反復は開始時点のスナップショット（to_array()）に対するもので、ループ変数への代入の書き戻しもスナップショット側に効きます（本体には戻りません）。条件に書くと「空でなければ真」で判定されます。
