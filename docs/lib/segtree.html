    ライブラリ — クラス

    SegTree<T>

    セグメント木。点更新と区間への二項演算がどちらも O(log n)

    セグメント木です。区間への二項演算 op とその単位元 e を持ち、1点の更新と、半開区間 [l, r) への演算（積）をどちらも O(log n) で行います。演算は要素型では決められない（同じ int でも和・最小・最大・gcd と変わる）ため、コンストラクタで関数値として受け取ります（AtCoder Library と同じ方式）。

    構築は t = SegTree(n, e, op)（長さ n、全要素 e）と、t = SegTree(a, e, op)（配列 a から構築）の2通りです。op には名前付き関数か、fn 型の注釈つき変数へ入れたラムダを渡してください。型変数を含む引数型へラムダを直接渡す書き方は、型検査の制限で通りません。

    メソッドと演算

    シグネチャ内容
    SegTree(n: int, e: T, op: fn(T, T) -> T)長さ n、全要素 e で構築する
    SegTree(a: [T], e: T, op: fn(T, T) -> T)配列 a の内容で構築する
    set(i: int, x: T)位置 i の要素を x に置き換える
    get(i: int) -> T位置 i の要素を返す
    prod(l: int, r: int) -> T半開区間 [l, r) の積 op(a[l], ..., a[r-1])。空区間は e
    all_prod() -> T全区間の積
    len要素数（プロパティとして t.len と書く）

    注意

    • 添字・区間の範囲外アクセスは未定義です（他のコンテナと同様、検査はしません）。0 <= l <= r <= len の範囲で使ってください
    • op は結合法則を満たし、e がその単位元であることが前提です（op(e, x) == op(x, e) == x）。交換法則は不要で、左から右への順序が保たれます
    • 要素型 T が配列の場合、要素は値セマンティクスで複製されます

    関連項目

    • LazySegTree<T, F> — 遅延セグメント木。区間への作用の適用と区間の積がどちらも O(log n)
    • array<T> — 配列。リテラル [1, 2, 3] が作る、要素型 T の列
    • Vec<T> — 伸びる配列。末尾への追加が均し定数時間
