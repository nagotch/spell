    ライブラリ — クラス

    Pos2

    二次元座標。リテラル (1, 2) が作る

    グリッド上の座標を表すクラスです。式の位置で (1, 2) と書くとこの型のリテラルになります（4つ以上の要素はエラーです）。要素ごとの演算と比較を備え、__hash__ があるため Dict のキーにできます。

    フィールド

    名前型内容
    xint第0成分
    yint第1成分

    メソッドと演算

    シグネチャ内容
    p + q / p - q要素ごとの加減（__add__ / __sub__）
    p * nint とのスカラー倍（__mul__）
    p == q / p != q要素ごとの等価性
    p < q / p <= q辞書順（x、次に y の順で比較）
    p[i]成分の読み取り。p[0] が x、p[1] が y。範囲外は検査されない
    __hash__()成分からのハッシュ。Dict のキーに使える
    __str__()空白区切り（"1 2" の形）

    座標添え字 a[p]

    入れ子配列への添え字としても使えます。a[p] は a[p[0]][p[1]] と同じで、第0成分が外側（グリッドでは行）です。添え字は段ごとに回り込みます。座標はちょうど1回だけ評価され、代入先（a[p] = v）でも使えます。安全添え字 a?[p] の形もあり、その場合は座標の段も含めて範囲が検査されます。

    注意

    • __bool__ は無いため、座標を条件に書くのはコンパイルエラーです
    • ゼロ値は zero_pos2() で、Deque<Pos2>() のような引数なし構築の埋め草にも自動で使われます
