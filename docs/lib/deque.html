    ライブラリ — クラス

    Deque<T>

    両端キュー。Queue としても Stack としても使える

    円環バッファで実装された両端キューです。両端の出し入れは、容量の倍増を除いて定数時間です。構築は Vec と同じく、引数なしの q = Deque()（要素型は int）、型引数つきの q = Deque<str>()、注釈つきの q: Deque<str> = Deque()、ファクトリを渡す q: Deque<int> = Deque(zero_int)、型を引数として渡す q = Deque(Pos2) や q = Deque([int]) の各形で書けます。

    出し入れの実体はダンダー __push_back__ / __push_front__ / __pop_back__ / __pop_front__ で、公開メソッドはその薄いラッパーです。矢印演算子でも出し入れできます。

    メソッドと演算

    シグネチャ内容
    push_back(v: T)末尾へ追加する（戻り値なし）
    push_front(v: T)先頭へ追加する（戻り値なし）
    pop_back() -> T末尾を取り出して返す
    pop_front() -> T先頭を取り出して返す
    front() -> T先頭を覗く（取り出さない）
    back() -> T末尾を覗く（取り出さない）
    len要素数（プロパティとして q.len と書く）
    q[i]論理位置の読み取り（0 が先頭）。書き込み用の __setitem__ は無い
    to_array() -> [T]先頭から末尾の順の通常配列のコピー

    注意

    • 空のときに pop_front / pop_back / front / back を呼ぶのは誤りで、結果は不定です（検査はしません）。呼ぶ前に len を確認してください
    • 反復と to_array() は開始時点のスナップショットに対するものです
    • 条件に書くと「空でなければ真」で判定されるため、while q: で空になるまで回せます
