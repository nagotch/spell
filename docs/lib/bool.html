    ライブラリ — クラス

    bool

    真偽値。true / false と短縮形の T / F

    リテラルは true / false で、短縮形の T / F も同じ意味です（型注釈の位置の T は型パラメータのままです）。実体は int と同じ生の値で、真は 1、偽は 0 として扱われます。比較の結果や、__bool__ を持つ値の条件判定の結果がこの型になります。

    メソッド

    シグネチャ内容
    __hash__()真は 1、偽は 0。Dict のキーに使える
    __str__()true / false

    注意

    • int との比較（1 == true など）はできます
    • 条件にクラス・配列・文字列を書くと、その __bool__ で判定されます。__bool__ の無いクラスを条件に使うのはコンパイルエラーです
