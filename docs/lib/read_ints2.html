    ライブラリ — 関数

    read_ints2

    整数を h 行 × w 列で読んで [[int]] にする。in[h][w] の実体

    式 in[h][w] の実体です。各行は独立した配列で、行同士が共有されることはありません。行の並びは入力の並びのまま（第0成分が行）です。

    関係する糖衣構文

    • >> 名前[個数][個数]（個数形）（糖衣集 §02）

    関連項目

    • read_ints — 整数を n 個読んで [int] にする。in[n] の実体
    • array<T> — 配列。リテラル [1, 2, 3] が作る、要素型 T の列
    • Pos2 — 二次元座標。リテラル (1, 2) が作る
