リファレンス

演算子と糖衣構文、prelude が用意する型とメソッド、入出力の形の一覧です。 振る舞いの大半は prelude のクラス定義で決まります。迷ったら prelude.sp が正本です。

01演算子

分類演算子備考
算術+ - * / %/ と % は床除算（Python 式）。型ごとの意味はダンダーメソッドで定義される
比較== != < <= > >=連鎖できる（0 < x < 10）。配列に < 系はない
論理&& || !短絡評価
代入= += -= *= /= %=複数代入 a, b = b, a も可。右辺を先に全部評価する
増減++ --後置のみ
範囲.. ..=a..b は半開、a..=b は終端を含む。降順も可
添字・メンバa[i] a.x a.m()添字は __getitem__ / __setitem__ へ展開。0引数メソッドは括弧を省略できる
関数値x -> 式、fn(...) { }矢印形は式1つの無名関数。fn 形は本体がブロック

02糖衣構文と正規形

記号形はすべて、通常の構文への書き換えとして定義されています。

記号形正規形・意味
<< x;、文頭の < x;x を文字列化して1行で出す
>> x;x = in;（整数を1つ読んで代入）
i@n { }for i in n { }（0 から n−1）
i@a..b { }for i in a..b { }
x@a { }for x in a { }（要素の走査）
@n { }変数なしで n 回繰り返す
!;break;
^;continue;
a- = in[n];整数を n 個読み、各要素から1引いた配列を代入する
x.rev範囲・配列・文字列の逆順（コピーを返す）

03組み込み型とメソッド

起動時に読み込まれる prelude が定義する型です。メソッドのうち引数を取らないものは、 呼び出しの括弧を省略できます（例: a.len）。

型持つ操作備考
int四則演算、比較、__hash__、反復（for i in n）64ビット整数
bool__hash__、文字列化（true / false）条件式の型
str+ 連結、== / !=、len、rev、添字（文字コードを返す）、反復、__hash__中身は文字コードの配列
[T]（array）+ 連結、* 繰り返し、== / !=（中身の比較）、len、rev、添字、反復、__hash__[値; 長さ] で埋めて作れる
Range反復、reva..b / a..=b の値
Dict<K, V>d[k] 読み（無ければ既定値を生やす）、d[k] = v 書き、has(k)、len、keys()、キー列挙の反復構築時に既定値ファクトリを渡す。キーには __hash__ が要る
fn(A) -> B呼び出し関数値の型。外側の変数は値で捕捉する

既定値ファクトリとして zero_int、zero_bool、zero_str が用意されています。 自作クラスが __hash__ と __eq__ を持てば、辞書のキーにも使えます。

04入出力の形

形意味
x = in;整数を1つ読む
a, b = in;整数を複数読む
a = in[n];整数を n 個読んで配列にする
a = in[h][w];h 行 × w 個の二次元配列として読む
s = in_str;、ws = in_str[n];空白区切りのトークンを1つ / n 個読む
s = in_line;行全体を1つ読む（空白を含む）
a- = in[n];読みながら各要素から1引く（1始まり入力用）
put x;、put x, y;値を空白区切りで1行に出す。配列は要素を並べて出し、二次元配列も平らに1行になる
yn 条件;真なら Yes、偽なら No を出す

05キーワード

def、class、return、if、elif、else、 while、for、in、break、continue、fn、 put、yn、そして入力の in / in_str / in_line です。 コメントは // と /* */ が使えます。

06型注釈を書ける場所

  • ローカル変数の初回束縛: x: int = 式
  • 関数の引数と戻り値: def f(x: int) -> int { }
  • クラスのフィールド: data: [int]（こちらは必須）
  • 関数値の型: f: fn(int) -> int

型パラメータはクラス定義側で明示し（最大4つ）、生成側では推論されます。 どちらからも決まらない場合は、注釈を求めるエラーになります。
