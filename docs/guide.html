言語ツアー

文法を基礎から一通りたどります。出てくる例はすべて、現在のコンパイラで実行して出力を確かめたものです。

01文と出力

プログラムはトップレベルに文を並べて書きます。文は ; で終えますが、; は省略できます。その場合、文の終わりは改行でなければなりません（同じ行に次の文を続けるには ; が要ります）。ブロック { } の直後はどちらも要りません。 式の途中での改行は、括弧の中では自由です。演算子の直後なら被演算子を次の行に置けますが、行末で式が完結していると次の行は新しい文として読まれます。 出力の基本は put で、複数の値を空白区切りで1行に出します。 糖衣として、文頭の < と << も同じ出力です。

上の3行はいずれも「値を文字列化して改行つきで出す」動きで、数値は10進、bool は true / false、 配列は要素を空白区切りで並べた形になります。

eprint は print の標準エラー版です。文字列化と改行は print と同じで、行き先だけが標準エラーになります。 デバッグ出力や診断を、答えの標準出力と混ぜずに出したいときに使います。

02変数と型

変数は代入で生まれます。型は初期値から推論されるのが基本で、必要なら x: int = 式 のように 注釈を付けられます。注釈はキャストではなく制約で、合わない値を入れようとすると型エラーになります。 基本の型は int（64ビット整数）、bool、str、そして配列 [T] です。 複数の変数への同時代入もでき、右辺をすべて評価してから代入するので交換がそのまま書けます。

03数と演算

四則演算と剰余があり、除算と剰余は Python と同じ床除算です （a == (a / b) * b + a % b が常に成り立ちます）。 比較は連鎖でき、0 < x < 10 は「0 < x かつ x < 10」で、 真ん中の式は1回だけ評価されます。論理演算は &&、||、! で、短絡評価します。 複合代入 += などと、後置の ++ / -- もあります。

04分岐とループ

if / elif / else と while があります。 for は反復対象を in の後に書く形で、整数なら「0 から その数−1」、 範囲なら 1..=20 のような区間、配列や文字列ならその要素をたどります。 範囲は a..b が半開区間、a..=b が終端を含み、始点が終点より大きければ自動で降順になります。 break しなかったときだけ実行される for ... else も Python と同じ意味です。

短縮形

ループには @ を使った短縮形があります。i@n { } は for i in n { }、 @n { } は変数なしの n 回繰り返し、@ { } は while true { }（無限ループ）です。また break は !;、 continue は ^; とも書けます。

降順の範囲もそのまま書けます。3..0 は集合としては 0..3 と同じで、順序だけが逆になります。

配列と文字列の反復では、ループ変数への代入がその要素へ書き戻ります （break / continue で抜ける場合も、その時点の値が書き戻ります）。 範囲や Dict のキーの反復では書き戻し先がないため、ループ変数への代入はエラーになります。 文字列を反復すると1文字ずつの文字列が得られます（添字 s[i] は文字コードの int を返します）。

05配列と文字列

配列は [3, 1, 4] のようなリテラルと、[0; 5] のような「値と長さ」の形で作れます。 長さは a.len、逆順のコピーは a.rev です。+ は連結、* は繰り返し、 == は中身の比較になります。これらはコンパイラの特殊扱いではなく、 prelude の array クラスのメソッドとして定義されています。

文字列 str も同じ作りで、+ で連結、== で比較、.len と .rev を持ちます。 添字で取り出すと文字コード（int）が返ります。

06関数

関数は def で定義します。引数と戻り値の型注釈は任意ですが、書けば検査されます。 関数名は値として扱え、引数は6個までです。

07クラス

クラスは、フィールドを本体で型つきで宣言し、メソッドを def で書く形です。 継承はありません。self は明示します。コンストラクタは __init__ で、 正常に終わるすべての経路で全フィールドが初期化されていることがコンパイラに検査されます。 引数を取らないメソッドは、obj.m のように括弧を省略して呼べます （フィールドと同名のメソッドは置けません）。__str__ を定義すれば、出力の際の文字列化に使われます。

添字や演算子も、対応するダンダーメソッドを定義すれば自作クラスに持たせられます。 a[i] は __getitem__、a[i] = v は __setitem__、 for x in a は __iter__ の返すイテレータの __has_next__ / __next__、 という具合です。イテレータに __set_current__ を定義すると、ループ変数への代入が要素へ書き戻ります。 __eq__ を持たないクラスの == は同一性比較になります。

08ジェネリクス

クラスには型パラメータを最大4つまで付けられます。生成のときの型引数は、 コンストラクタの引数と、束縛先の注釈から推論されます。実装は単相化で、 使われた型の組み合わせごとに専用のクラスが生成されます。

09関数値とクロージャ

関数は第一級の値です。型は fn(int) -> int のように書きます。 無名関数は fn(x: int) -> int { } の形と、式だけの x -> x * x という矢印形があります。 外側の変数は値で捕捉され、クロージャになります。

10辞書

Dict<K, V> は prelude のクラスです。キーは __hash__ と __eq__ を持つ型なら何でも使えます。 読み取り d[k] は、キーが無ければ「構築時に渡したファクトリが作る既定値」を登録してから返す、 いわゆる defaultdict 式です。数え上げがそのまま書けます。 既定値ファクトリはキーごとに呼ばれるので、値が共有されることはありません。 反復はキーを挿入順にたどります。

zero_int、zero_bool、zero_str は prelude が用意する既定値ファクトリです。 配列のような値は Dict(fn() -> [int] { return []; }) のようにラムダで渡します。 生成には型の手がかり（注釈など）が要ります。辞書自体に文字列化は無いので、そのまま put には渡せません。

Vec（伸びる配列）

Vec<T> は末尾へ追加していける配列です。通常の配列は長さが作った時点で決まりますが、 Vec は append で伸びます（容量は倍々に広がるので、追加は均し定数時間です）。 生成には Dict と同じく既定値ファクトリを渡します。添字と len が見るのは論理長で、 反復は開始時点のスナップショットをたどります。配列として取り出すには to_array() を使います。

11入力

標準入力は代入の右辺で in と書きます。in[n] は整数を n 個読んで配列にし、 in[h][w] は h 行 × w 個の二次元配列にします。文字列は in_str（空白区切りのトークン）、 in_line（行全体）です。入力が1始まりのときは a- = in[n] と書くと、 読みながら各要素から1を引いてくれます。糖衣として >> x; という入力の形もあります。

Yes / No の出力には yn があります。yn 条件; で、真なら Yes、偽なら No を出します。

ファイルとコマンドライン引数

プログラムへの引数は args() で [str] として受け取ります。args()[0] はプログラム名です。 ファイルは read_file(path) が全体を読み、結果を FileData（ok: bool と text: str）で返します。 開けなかったり読み切れなかったりしたときは ok が false になります（空のファイルは ok が true で text が空です）。 write_file(path, text) は全体を書き、全部書けて閉じられたら true を返します。 exit(code) はその場でプロセスを終わらせます（出力は flush されます）。

12エラー

コンパイルエラーは日本語で、位置と理由を示します。型の不一致、未定義の名前、構文の誤りが対象で、 最初のエラーで処理が止まります。下の例は、bool を int の変数へ入れようとしたときの実際の表示です。

言語サーバー spell-lsp を使えば、この診断はエディタの中にもそのまま出ます（エディタ連携）。
