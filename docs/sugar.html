糖衣集

spell の糖衣構文だけを集めたページです。糖衣はどれも、読みにくい記号の裏に素直な正規形を持ちます。 各項目に「記号形 → 正規形」の対応と、実行できる短い例を付けます。 機能そのものの説明はリファレンス側にあります。

01出力の糖衣

<< 式

記号形正規形
<< xprint(x)

put 値, 値, ...

記号形正規形
put a, b値を空白区切りで並べて改行まで出す文（print の文形。引数は1つ以上）

yn 式

記号形正規形
yn 式式が真なら Yes、偽なら No を1行出す

02入力の糖衣

>> 対象, 対象, ...

記号形正規形
>> a, ba = in; b = in（左から順に読む）

>>> 対象, 対象, ...

記号形正規形
>>> s, ts = in_str; t = in_str（空白区切りのトークンを左から順に読む）

対象は >> と同じく空白区切りでも並べられ、カンマと混在できます（空白区切りの継続は同じ行の中だけです）。

>> 名前[個数][個数]...（個数形）

記号形正規形
>> a[n]a = [0] * n のあと i@n { >> a[i]; }（個数式は1回だけ評価される）
>>> s[n]s = [""] * n のあと i@n { >>> s[i]; }
>> a[n][m]a = [[0]; n] のあと i@n { a[i] = [0] * m; j@m { >> a[i][j]; } }（二次元。角括弧を重ねれば n 次元になる）

基底名が未束縛のときだけ個数形になります。束縛済みの配列への >> a[2] は従来どおり添字形（1要素へ1つ読む）です。 個数形では角括弧の並びが全て個数になり、入れ子配列を作って全要素を行順に読みます（直方体のみ）。 小配列は枠ごとに新しい配列になるので、行同士が同じ配列を共有することはありません。 いずれかの個数が 0 なら、その方向は空になります。角括弧の継続は同じ行の中だけです。

対象- = in[n]

記号形正規形
a- = in[n]整数を n 個読み、各値から 1 を引いた配列を代入する

03繰り返しの糖衣

@ 系

記号形正規形
i@n ブロックfor i in n ブロック（0 から n−1）
i@a..b ブロックfor i in a..b ブロック（..= も可）
x@a ブロックfor x in a ブロック（反復対象の要素走査）
@n ブロックfor _ in n ブロック（回数だけの繰り返し）
@{} / @:while (1 == 1) { }（無限ループ）
@? 条件 ブロックwhile 条件 ブロック（@ 式 は回数の形なので、条件の印 ? を足して区別する。条件には __bool__ も効く）

ブロックは { } 形式でも : 形式でも書けます（§05）。

!; と ^;

記号形正規形
!;break
^;continue

for...else

記号形正規形
for ... { } else { }break しなかった（反復が最後まで回った）ときだけ else 側を実行する

| の else / elif

記号形正規形
| 式 ブロックelif 式 ブロック
| ブロックelse ブロック

| の直後がブロック（: か { }）なら else、式が続けば elif として読みます。キーワード形との混在もできます。for...else の else も | で書けます。

04式の糖衣

連鎖比較

記号形正規形
a < b < ca < b && b < c（ただし中間の b は1回だけ評価される）

複数代入

記号形正規形
a, b = x, y右辺を全部評価してから、左から順に代入する

ラムダの矢印 x -> 式

記号形正規形
x -> 式fn(x) { return 式 }
(x, y) -> 式fn(x, y) { return 式 }

引数の型は、注釈や関数の引数位置などの期待型から決まります（上の例の fn(int) -> int という注釈がそれです）。 期待型が無い場所では引数の型が決まらず、エラーになります。 ただし、左辺の名前がすでに束縛されている場合は、ラムダではなく矢印演算子として解決されます（次の項目）。

矢印演算子 <- / ->

記号形正規形
q <- vq.__push_back__(v)
v -> qq.__push_front__(v)
x <- qx = q.__pop_front__()
q -> xx = q.__pop_back__()
a <- b（両辺 int）a < -b
a -> b（両辺 int）a > -b

解決はこの順（push → pop → 比較）で、該当するものが無い場合はエラーになります。連鎖（a <- b <- c）はできません。

複合代入

記号形正規形
x += e（-= *= /= %= も同様）x = x + e（演算はダンダーへ展開される）

++ / --

記号形正規形
x++x = x + 1（式の値も代入後の値）
x--x = x - 1

.rev

記号形正規形
a.rev逆順にしたコピー（配列・文字列は新しい値、Range は向きを反転した範囲）。元は変わらない

座標リテラル (1, 2)

記号形正規形
(式, 式)Pos2(式, 式)
(式, 式, 式)Pos3(式, 式, 式)

式の位置のカンマ区切り括弧リストは、座標クラス Pos2 / Pos3 の構築として読まれます。要素は任意の式です。 要素が4つ以上あるとエラーになります。(式) は従来どおりの括弧式で、関数呼び出しの引数リストや (x, y) -> 式 のラムダとは混同されません。 配列リテラルの要素位置でも使えるため、方向ベクトルの表をそのまま書けます。

座標添え字 a[p]

記号形正規形
a[p]（p: Pos2）a[p[0]][p[1]]
a[p]（p: Pos3）a[p[0]][p[1]][p[2]]

添字の型が Pos2 / Pos3 のとき、入れ子配列への多段添字に展開されます。座標 p は一度だけ評価されます。 深さは座標の次元で決まり、配列の入れ子の深さと一致しない場合はエラーになります。読み取りと代入の両方で使えます。 Dict のキーとしての d[p] は対象外で、従来どおりキー照合になります。

安全添え字 a?[i][j]

記号形意味
a?[i][j]...（単独）全段とも範囲内なら true
a?[i][j]... == 式 などの比較どこかの段で範囲外なら比較全体が false、全段範囲内なら要素の通常の比較

対象の直後に ? を1回だけ置き、後ろは通常の添え字の連鎖を続ける形です（段ごとに ? は繰り返しません）。 対象にできるのは配列と str だけで、対象と各添え字はちょうど1回だけ評価され、範囲チェックは浅い段から順に短絡します。 座標添字と組み合わせることもでき、要素が str の配列では末尾の文字列も1段と数えるため、グリッドの隣接マスを盤外チェックなしに調べられます。 代入先と連鎖比較の中では使えません（コンパイルエラー）。

スライス x[i:j]

記号形意味
x[i:j]i 以上 j 未満の部分（新しい配列／文字列）
x[i:] / x[:j] / x[:]端の省略。省略した側は端まで
x[-3:]負の添え字は末尾から数える

正規形は prelude のメソッド __slice__(lo, hi) の呼び出しで、境界の正規化（省略は 0／長さ、負数は末尾から、範囲外は端に丸め、上限が下限未満なら空）はコンパイラが行います。 対象にできるのは配列と str で、結果は要素をコピーした新しい値です（元の値は変わりません）。 ステップ（x[i:j:k]）は無く、代入先と安全添え字の中では使えません（コンパイルエラー）。

05文とブロックの糖衣

セミコロンの省略

記号形正規形
改行で文を終える; で文を終える

; を省略した場合は、改行が文の終わりになります。同じ行に文を続けるには ; が要ります。 ブロック { } の直後にはどちらも要りません。

: ＋インデントのブロック

記号形正規形
def f(): 文...（インデントで区切る）def f() { 文... }

: 形式と { } 形式は等価で、ブロックごとに独立に選べます（混在も可）。 対象は def / class / if / elif / else / while / for と @ 系です。 : の同じ行に文を1つ書く1行形も使えます。ラムダ fn の本体だけは { } のみです。

文頭の ?（if の糖衣）

記号形正規形
? 条件: 文...if 条件: 文...

文の頭の ? は if の別名です。条件の括弧は任意で、ブロックは : 形式と { } 形式のどちらでも書けます。 後ろに elif / else を続けることもできます。? が使えるのは文の頭だけで、式の中では使えません。

0引数メソッドの括弧省略

記号形正規形
a.len、q.pop_backa.len()、q.pop_back()（引数の無い呼び出し）

フィールドとメソッドが同名の場合は、括弧なしがフィールド、括弧ありがメソッドになります。
